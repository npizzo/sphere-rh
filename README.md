# Spherical turbulence: results and protocols

A research record of Rossby–Haurwitz waves, spectral condensation, and the long-time behavior of two-dimensional flow on a sphere.

The project revisits Figures 5–6 of Salmon & Pizzo (2023): a degree-six wave on a rotating background, and initially equal energy in degrees four, five, and six with zero relative angular momentum. The long-time extension compares normalized patterns over observation intervals that grow with the age of the flow.

## Read the results

The site deploys through GitHub Pages. `results.json` records run status and links to measured figures and diagnostics. An empty run catalog means that no analyzed results have been published. A completed calculation does not establish convergence to an asymptotic end state.

Seeded calculations reproduce the experiment protocols; the original paper's random realization is not asserted to be reproduced. Data are interpreted in the stated reference frame, and conservation and numerical-resolution checks accompany scientific interpretation.

## Publication scope

This repository contains the results website, experiment descriptions, and publication assets. The numerical solver, supplied original Fortran programs, full source history, and raw simulation fields are maintained separately. The website does not imply that those sources are publicly available.

Only figures and summaries produced from measured simulations belong in the results catalog. Public artifacts must omit private filesystem paths, account details, and credentials.
